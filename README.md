# 🌟 WeatherNova ⛅

Welcome to **WeatherNova**, a modern, visually appealing weather web app designed to provide accurate weather information for cities around the world. Powered by Spring Boot and OpenWeatherMap, WeatherNova is ideal for learning full-stack web development with real API integration.

---

## 🌍 Overview

**WeatherNova** enables users to:

- Search for weather by city name
- View current temperature, weather description, humidity, and wind speed
- Experience a clean, responsive UI with weather-themed icons
- Navigate seamlessly with simple, elegant design

---

## ✨ Features

- 🌦️ Live weather data via OpenWeatherMap API
- 🌍 Global city support
- 🎨 Gradient background and weather icons
- ✅ Error handling for invalid entries
- 🖥️ Responsive and mobile-friendly design

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, Bootstrap 4, Thymeleaf
- **Backend**: Java 17+, Spring Boot
- **API**: [OpenWeatherMap API](https://openweathermap.org/api)
- **Icons**: Weather Icons CSS
